## 3. Phase 2：全局批量清洗

### 3.1 清洗 YAML 头部

每篇开头有 Zendesk 元数据。用脚本统一移除 `source_url`、`external_id`、`vote_sum` 等字段，保留 `title`：

```python
import re, pathlib

root = pathlib.Path("storage/export/articles")
for md in root.rglob("*.md"):
    text = md.read_text(encoding="utf-8")
    m = re.match(r"^---\n(.*?)\n---\n", text, re.S)
    if m:
        lines = [l for l in m.group(1).splitlines()
                 if l.startswith("title:")]
        text = "---\n" + "\n".join(lines) + "\n---\n" + text[m.end():]
        md.write_text(text, encoding="utf-8")
```

4. 原文 bug 顺手修：Super 篇 380gsm/400gsm 自相矛盾

**明信片（4 篇）**：四篇结构一致，可一次改完模板后复用——尺寸档、纸型对比表、背面数量、信封说明

**文具（3 篇）**：按产品线决定去留；Notecards 篇 5.82"/5.83" 不一致问题顺手修

**尺寸模板（保留的 ~10 篇）**：
1. 按你的成品尺寸 + 出血重算每个像素尺寸表（公式：`(成品英寸 + 出血×2) × 300dpi`）
2. 重制 AI/PSD/InDesign 模板文件，上传到你自己的服务器
3. 总纲篇（How-to-Use）按你的印厂规范改：出血/安全区 mm 数、ICC profile、PDF 预设

## 7. 执行前需要你提供的信息（阻塞项）

1. **品牌名**（中/英文）、域名、客服邮箱/电话、在线客服时间

7. **印厂印前规范**：出血 mm 数、ICC profile、文件格式要求、文件大小上限（原文 50MB 与 25MB 矛盾，需你定稿）
